|Admin| usage |
|------|--------|
|Promote|Makes a user an admin|
|Demote|Removes admin status|
|Remove|Removes a user|

|Media| usage |
|----|--------|
|Spotify|Downloads songs from Spotify|
|YouTube video|Downloads video from YouTube|
|YouTube audio|Downloads audio from YouTube|

|General| usage |
|----|--------|
|Admins|Tags all admins in a group|
|Everyone|Tags all participants in a group; admins only|
|Flow|Shows the AKURA group links|
|Help|Displays available commands and command details|
|Mods|Displays moderator contact info|
|Profile|Displays a generated profile for a tagged or mentioned user|
|Support|Shows the AKURA support groups (same list as `.flow`)|
|Xp|Views a tagged user's XP|

|Fun| usage|
|----|--------|
|Triggered|Triggers a photo when commanded|
|Chess|Launches a game of chess in the group chat|

|Misc| usage|
|----|--------|
|Delete|Deletes the quoted message; admin only|
|Hi|Checks that the bot is online|
|Akura|Displays bot information|

|Moderation| usage|
|----|--------|
|Activate|Activates selected bot features in a group chat|
|Deactivate|Deactivates selected bot features in a group chat|
|Promote|Promotes a tagged user when the command user is a group admin|
|Demote|Removes admin status from a tagged user when allowed|
|Remove|Removes a tagged user when the bot and command user are group admins|

|Utils| usage|
|----|--------|
|Blur|Blurs a tagged image or the command user's profile picture|
|Sticker|Converts an image or GIF into a WebP sticker|
|Subred|Fetches a subreddit post based on a search|

|Dev| usage|
|----|--------|
|Disable|Disables a bot command|
|Enable|Enables a disabled bot command|
|Eval|Evaluates JavaScript|
|Ban|Bans a user from using the bot|
|Unban|Unbans a user|
